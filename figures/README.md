# Figure Purpose

The figures are used to analyze:
- agent behavior,
- energy efficiency,
- monitoring coverage,
- sustainability,
- robustness,
- environmental adaptation.

---

# Experimental Focus

The visualizations support the paper’s central argument that:
- lightweight utility-based reasoning,
- combined with lightweight outcome learning,

can produce effective and interpretable environmental monitoring behavior.
