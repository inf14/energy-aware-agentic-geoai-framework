# Disclaimer

This repository contains the research implementation, experimental framework, and supporting material associated with the project:

**Energy-Aware Agentic Geo-AI Framework**

The repository is intended for:
- research reproducibility,
- educational use,
- implementation reference,
- experimental demonstration.

# Publication Notice

The full manuscript/book chapter associated with this work is not included in this repository.

The repository only contains:
- implementation code,
- processed experimental results,
- visualizations,
- supporting documentation.

# Research Scope

This framework is designed as a lightweight and interpretable experimental Geo-AI platform.

It is not intended to represent:
- a production-ready monitoring system,
- a high-fidelity robotics simulator,
- a deployment-grade autonomous platform.
