# Experimental Results

This directory contains processed outputs from the experimental evaluation of the Geo-AI framework.

---

# Result Files

| File | Description |
|---|---|
| performance_summary.csv | Aggregate performance comparison across agent types |
| stress_test_results.csv | Sustainability evaluation under environmental volatility |

---

# Evaluation Metrics

The experiments evaluate:

| Metric | Meaning |
|---|---|
| Energy Used | Total energy consumed during monitoring |
| Coverage | Total spatial monitoring coverage achieved |
| Sustainability | Coverage achieved per unit energy consumed |

---

# Agent Configurations

The repository evaluates three agent configurations:

| Agent | Description |
|---|---|
| Constraint-only agent | Uses rule-based feasibility constraints only |
| Utility-based agent | Uses utility reasoning without learning |
| Utility + outcome learning agent | Uses utility reasoning with lightweight online learning |

---

# Experimental Conditions

Experiments include:
- multiple random seeds,
- varying environmental volatility,
- independent trials,
- comparative benchmarking.

---

# Notes

The repository includes only the processed results and tables used in the final manuscript.
